# plumOS mini PLUS v0.1.0

## 日本語

GKD mini PLUS用のSDカードイメージです。

1. `plumos-mini-plus-v0.1.0-sd-image.7z`と同名の`.sha256`をダウンロードし、チェックサムを確認します。
2. 7zを展開して`plumos-mini-plus-v0.1.0-sd-image.img`を取り出します。
3. Raspberry Pi ImagerやbalenaEtcherで、16GB以上のmicroSDへイメージを書き込みます。書込み先のデータは消去されます。
4. 電源を切った本体の上部SYSスロットへ挿入し、起動します。初回のストレージ準備が終わり、メニューが表示されるまでお待ちください。
5. SD1のPLUMOS内`Roms/<system>/`へROM、`BIOS/`へ必要なBIOSを追加します。

SD2を使う場合はFAT32でフォーマットし、ルートに`roms/<system>/`と`bios/`を作成してください。SDカードは電源を切ってから着脱してください。ROM・市販ゲームのBIOSは同梱していません。

操作や設定は[日本語マニュアル](https://github.com/game-de-it/plumOS-mini-PLUS/blob/mini-plus-port/docs/user/README.ja.md)をご覧ください。

## English

SD card image for GKD mini PLUS.

1. Download `plumos-mini-plus-v0.1.0-sd-image.7z` and its `.sha256` file, then verify the checksum.
2. Extract the 7z archive to obtain `plumos-mini-plus-v0.1.0-sd-image.img`.
3. Write the image to a 16 GB or larger microSD using Raspberry Pi Imager or balenaEtcher. All existing data on the target card will be erased.
4. With the device powered off, insert the card into the top SYS slot and power on. Wait for first-boot storage preparation to finish and the menu to appear.
5. Add ROMs to `Roms/<system>/` and the required BIOS files to `BIOS/` on SD1's PLUMOS volume.

For optional SD2, format it as FAT32 and create `roms/<system>/` and `bios/` at its root. Power off before inserting or removing either card. ROMs and commercial game BIOS files are not included.

See the [English manual](https://github.com/game-de-it/plumOS-mini-PLUS/blob/mini-plus-port/docs/user/README.md) for controls and settings.
