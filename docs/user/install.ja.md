# SD1への書込みと初回起動

[English](install.md) | [マニュアル](README.ja.md)

現在はリリース前の開発段階です。試験で指定された候補を使ってください。古いイメージには後の修正が含まれない場合があります。[現在の状態](../../README.ja.md)も確認してください。

1. GKD mini PLUSと、本体上部SYS用の16GB以上のmicroSDを用意します。
2. raw `.img`とSHA-256を入手します。圧縮されている場合だけ先に展開します。開発版は非圧縮の場合もあります。
3. ハッシュを照合し、Raspberry Pi Imager・balenaEtcher等でカードの名称と容量を確認して対象を選びます。
4. ディスクイメージとして書き込み、検証後に安全に取り外します。
5. 電源OFFの本体へSD1を挿入して起動し、初回進捗が完了してFEが表示されるまで待ちます。

進捗画面ではストレージを準備し、本体管理領域を8GiBへ拡張して、残りをPLUMOS FAT32利用者領域にします。途中で電源を切らないでください。通常起動ではこの初回処理を省略します。

書込みは対象カードのセーブ・設定を含め消去します。既存カードは先にバックアップしてください。書込みソフトの完了・取り外しは実機起動確認とは別です。

任意のSD2はFAT32でフォーマットし、ルートに`roms/<system>/`と`bios/`を作成します。電源OFFで本体下部SD2へ挿入してください。SD2なしではSD1のPLUMOS内`Roms/`・`BIOS/`を利用します。[ストレージ](storage.ja.md)・[ネットワーク転送](network.ja.md)・[ゲーム操作](emulators.ja.md)も参照してください。
