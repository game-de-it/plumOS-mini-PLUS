# plumOS mini PLUS v0.1.0

## 日本語

GKD mini PLUS（RK3566 / ARM64）向けplumOSの初回正式版です。
plumOS-Bubbleの資産を基に、mini PLUSの起動・表示・入力・音声・Wi-Fi・電源管理へ対応しました。

### 主な機能

- コントローラー操作のFE、Text・Graphic・Gallery表示、画像スクレイピング、お気に入り、GGFE。
- RetroArch・PicoArch・単体エミュ、114 libretro core、97 catalog entry・196起動経路。
- PortMaster・Pyxel・File Manager・Music Player・SD2修復。
- Wi-FiとSSH・SFTP・FTP・Samba。SD2のROM/BIOSを優先し、未装着時はSD1を利用。
- スピーカー・イヤホンの音声切替、音量操作、SELECT＋音量ボタンによる20段階輝度変更。
- SDR104対応による起動高速化、ゲーム中の安全な再起動・シャットダウン、USB充電接続あり／なしのSleep復帰。
- 署名付きRuntime更新と、対応bootでのSystem A/B試行起動・正常確定・失敗時rollback。

### インストールと基本操作

1. `plumos-mini-plus-v0.1.0-sd-image.7z`とチェックサムを取得し、SHA-256を確認します。
2. 展開した`plumos-mini-plus-v0.1.0-sd-image.img`を16GB以上のmicroSDへディスクイメージとして書き込みます。既存データは消去されます。
3. 電源OFFで本体上部SYSへ挿入して起動し、初回ストレージ準備の進捗が完了するまで待ちます。
4. SD1のPLUMOS内`Roms/<system>/`・`BIOS/`へデータを用意します。任意のSD2はFAT32で、ルートに`roms/<system>/`・`bios/`を作ります。SD2は電源OFFで下部スロットへ着脱します。

非圧縮`.img`を提供する場合は展開不要です。更新パッケージとSD全体イメージの書込みは別操作です。

- Aで決定、Bで戻る、STARTでFEメニュー。
- **START右上の丸いキー**でRA/Pico等のメニュー。RAはQuit RetroArch、Pico/単体は各メニューの終了でFEへ戻ります。
- RAのSELECT＋STARTは終了確認が出た場合に繰り返します。portの操作・終了はタイトル別です。
- RA撮影はQuick Menu → Take Screenshot。撮影専用FNの物理位置は未確認です。
- Wi-Fi接続はSTART → Network Settings、転送serviceはNW Serviceから個別に有効化します。SSHがONでもSFTPは別設定です。
- 初期SSH/SFTPは`root` / `plumos`（port 22）。利用環境に応じてパスワードを変更してください。

### 確認範囲と既知の制限

開発カードで初回進捗・通常起動、入力・音声・輝度、SD1/SD2プレイ、Wi-Fi再接続、再起動・終了、USBあり／なしSleep復帰を確認しています。Runtime/System更新・復旧にも実機試験記録があります。

機械的な起動証拠は196経路中170、PCM進行は166経路です。残る26経路にはcontent・BIOS・親archive不足や外部port別試験等の制限を記録しています。全ゲーム・全coreの映像／可聴音／操作を一括保証するものではありません。

- USBは充電専用。ADB・HDMI出力・3DS・Java MEは未対応です。
- N64等の性能はゲームにより異なります。必要に応じてPerformance設定を使います。
- SD2の電源ON中の着脱は未対応です。System packageはkernel・DTB・initramfs・p2を更新しません。
- ROM、市販ゲーム、利用者のゲームBIOS・セーブ・Wi-Fi資格情報は含みません。同梱可能な補助データの由来・条件はNOTICEを参照してください。

## English

The first formal plumOS version for **GKD mini PLUS (RK3566 / ARM64)**. It reuses plumOS-Bubble assets with mini PLUS-specific boot, display, input, audio, Wi-Fi and power integration.

### Highlights

- Controller-driven FE with Text, Graphic and Gallery views, artwork scraping, favourites and GGFE.
- RetroArch, PicoArch, standalone emulators, 114 libretro cores, 97 catalog entries and 196 launch routes.
- PortMaster, Pyxel, File Manager, Music Player and SD2 repair.
- Wi-Fi, SSH, SFTP, FTP and Samba; optional SD2 ROM/BIOS priority with SD1 fallback.
- Speaker/headphone routing, volume controls and 20-step brightness using SELECT + volume.
- SDR104 boot acceleration; safe in-game reboot/shutdown and Sleep/resume with or without USB charging.
- Signed Runtime updates and System A/B trial, health commit and rollback on compatible boot images.

### Install and essential controls

1. Obtain `plumos-mini-plus-v0.1.0-sd-image.7z` and checksums; verify SHA-256.
2. Extract `plumos-mini-plus-v0.1.0-sd-image.img` and write it as a disk image to a 16 GB or larger microSD. Existing data is erased.
3. Insert it into the top SYS slot while powered off. Wait for first-boot storage progress to complete.
4. Supply content under SD1 PLUMOS `Roms/<system>/` and `BIOS/`. Optional FAT32 SD2 uses root `roms/<system>/` and `bios/`; insert/remove it in the bottom slot only while powered off.

A supplied uncompressed `.img` needs no extraction. Writing a full SD image is different from installing an update package.

- A confirms, B goes back, START opens the FE menu.
- The **round key above-right of START** opens RA/Pico/supported emulator menus. Quit RetroArch or the runtime's own exit item returns to the FE.
- Repeat RA SELECT + START if quit confirmation asks. Port controls/exits are title-specific.
- RA screenshots: Quick Menu → Take Screenshot. The separate screenshot FN's physical position is unconfirmed.
- Connect under START → Network Settings. Enable transfer services individually under NW Service; SSH does not automatically enable SFTP.
- Initial SSH/SFTP: `root` / `plumos`, port 22. Change passwords as appropriate for your network.

### Validation scope and known limits

Development-card checks cover first-boot progress/normal boot, controls/audio/brightness, SD1/SD2 gameplay, Wi-Fi reconnection, reboot/shutdown and USB/no-USB Sleep/resume. Runtime/System update and recovery have device-test evidence.

Machine launch evidence covers 170 of 196 routes, with advancing PCM on 166. The remaining 26 retain content/BIOS/parent-archive limits or separate external-port testing requirements. This is not a blanket visual/audible/input acceptance of all games and cores.

- USB is charge-only; ADB, HDMI output, Nintendo 3DS and Java ME are unsupported.
- N64 and other demanding systems vary by game; use Performance settings when needed.
- Powered SD2 hot-plugging is unsupported. System packages do not replace kernel, DTB, initramfs or p2.
- User ROMs, commercial games, game BIOS, saves and Wi-Fi credentials are not included. Notices describe provenance/terms for approved bundled support data.
