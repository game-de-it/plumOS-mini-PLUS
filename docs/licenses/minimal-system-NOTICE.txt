plumOS mini PLUS minimal System notice

The diagnostic read-only System contains plumOS-authored init and display
marker files, the statically linked BusyBox binary, and the Dropbear and
wpa_supplicant recovery-network clients from the pinned Debian Bookworm arm64
build environment.

plumOS-authored files use the repository MIT License. BusyBox, Dropbear,
wpa_supplicant, and their runtime libraries retain their upstream terms. The
System image packages the corresponding Debian copyright documents under
/usr/share/licenses.

The generated image also contains hash-pinned GKD mini PLUS stockOS boot
artifacts: the Rockchip boot prefix, Linux kernel, device trees, overlays and
fixup script. These files remain outside the plumOS MIT License and are
distributed under the GKD vendor permission recorded in
GKD-stockOS-PERMISSION-NOTICE.txt, subject to applicable third-party terms.

The System image includes the hash-pinned RTL8821CS module captured from the
GKD mini PLUS stockOS. Its vermagic is 4.19.172 and does not match the selected
4.19.193 mini PLUS stock kernel. plumOS first attempts a normal module load and
permits kmod's explicit force-load path only when the separately packaged
allow-rtl8821cs-force-load marker is present. This is an experimental recovery
network path, not evidence of ABI compatibility, and the module remains under
the GKD vendor permission and applicable upstream terms rather than plumOS MIT.
