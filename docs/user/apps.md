# Applications and exit methods

[日本語](apps.ja.md) | [Manual](README.md)

Open `START → Apps`. These are the visible application entries; helper jobs used by Scraping are not separate user apps.

| App | Purpose / return to FE |
| --- | --- |
| Scraping | Download artwork; follow [scraping](scraping.md), then use Back/exit |
| File Manager | Manage files with NextCommander; use its Exit command |
| Music Player | Play music; use its exit/back action |
| RetroArch | Configure RA; choose Quit RetroArch to return |
| Pyxel Setup | Configure/install Pyxel content; follow the on-screen prompts and exit |
| PortMaster | Install/manage ports; use its Quit/Exit menu |
| Update PortMaster | Update PortMaster's manager; wait for completion |
| Repair SD2 | FAT32 SD2 check/repair; read the prompt and press A again within five seconds |
| Game Gear | Dedicated Game Gear carousel; SELECT opens settings, including Exit |

Repair SD2 does not target SYS. Back up important files before repair and do not interrupt it.

PortMaster games have title-specific controls and exit methods. Check each game's instructions before launch; RA hotkeys do not apply universally. Install any required game data separately. The Apotris compatibility guard covers the documented v4.2.0 build using the tested v4.1.0 runtime; it does not guarantee all ports/versions.

In Game Gear, left/right selects, up/down jumps five, A launches and X changes the case view. B/START in the carousel do not exit; use SELECT → Exit. See [emulator controls](emulators.md) for RA/Pico menus after a game starts.

Do not power off during installs or updates. Package updates preserve downloaded ports and their installed-state data.
