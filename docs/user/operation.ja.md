# 基本操作と電源・スリープ

## フロントエンド

| 操作 | 動作 |
| --- | --- |
| 十字キー | システム、ゲーム、設定の移動 |
| `A` | 決定／ゲーム起動 |
| `B` | 戻る |
| `SELECT`（ゲーム選択中） | 利用可能なエミュレータ／コアを選ぶ |
| `START` | メインメニューを開く |
| 電源ボタン短押し | 電源メニューを開く |

空のシステムを隠すにはUI設定の`SHOW EMPTY SYSTEM`をOFFにします。ROMの追加・削除後
は一覧を更新するか再起動してください。

mini PLUSには4個のFNキーがあり、アナログスティックはありません。
ドライバが報告するABS軸やL3/R3という名前は、互換用の識別子です。

## 電源

電源ボタンのメニュー、または`START`メニューから`Reboot` / `Shutdown`を選びます。
ゲームが応答しない場合も、先にエミュレータを終了させてから再起動／終了する処理が
動きます。画面とLEDが消えるまでSDカードを抜かないでください。

## スリープ

電源ボタンでメニューを開いて`Sleep`を選び、電源ボタンをもう一度押すと復帰します。ゲーム中も利用できます。
復帰後は映像、操作、スピーカー／イヤホンの出力先を確認してください。

## 音量と画面

本体の音量－／＋buttonはゲーム中もsystem全体の音量を変更します。`SELECT`を押しながら
音量－／＋buttonを押すと、画面の明るさを20段階で変更できます。長押しにも対応します。
`START` → `システム設定`の`音量`と`明るさ`からも同じ値を変更できます。contrast、hue、
saturationもシステム設定から調整できます。

mini PLUSでは、液晶の有効なPWM範囲に合わせた機種専用の20段階カーブを使用します。

## 端子

- USB端子: 充電専用
- HDMI端子: 現在未対応
- SYS: 本体上部。起動用SD1
- SD2: 本体下部。任意のROM／BIOSカード

## 更新

`System Update`から署名付きRuntimeまたはSystem更新を選択できます。
Runtime更新はアプリ・core等を更新し、起動確認に失敗すると前の内容へ戻します。
System更新は対応するA/B起動処理がある場合に限り、未使用面へ書き込んで全読戻しを
検証します。次回起動で一度試し、FE起動後に確定します。起動完了しなければ次の起動で
以前の面へ戻します。更新中は電源を切らないでください。

古い起動処理ではSystem更新を拒否するため、対応するフルSDイメージへの書換えが必要です。
kernel・DTB・initramfs・p2 matching bundleは、このSystem更新packageの対象外です。
ROM、BIOS、利用者設定、save/stateを更新目的で上書きしません。
