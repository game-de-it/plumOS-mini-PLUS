## 3種類の表示

`START → UI Settings → UI Mode`でTextまたはGraphicを選びます。システム一覧・ROM一覧に適用されます。GalleryはROM一覧で`X`を押して開きます。UI Modeの3番目の設定ではありません。Galleryでは左右でゲーム移動、上下で5件移動、Aで起動、XでROM一覧、Bでシステム一覧へ戻ります。

FEの撮影先は`/storage/Screenshots/`です。エミュの撮影方法・保存先は異なるため[エミュ操作](emulators.ja.md)を参照してください。UI SettingsのSHOW EMPTY SYSTEMをOFFにすると空システムを隠せます。ROM追加後は一覧を更新するか入り直してください。

## 音量・輝度・電源

イヤホンを挿すとイヤホンへ、抜くとスピーカーへ音声が切り替わります。無音の場合はシステムとエミュ双方の音量を確認してください。ゲーム・アプリの保存中はSleepや電源操作を避けてください。

音量ボタンで音量を変更します。SELECTを先に押したまま音量−/＋を押すと、ゲーム中を含め20段階で輝度を変更できます。長押し連続変更も可能です。音量・輝度・コントラスト・色相・彩度はSystem Settingsからも変更できます。

電源ボタンを短く押すと電源メニューが開きます。Sleep・Reboot・Shutdownを選択し、Sleepからは電源ボタンで復帰します。USB充電接続あり・なしのSleep復帰を確認済みです。ゲーム中の再起動・終了はゲームを停止してから実施するため、先に保存してください。

シャットダウンが完了し画面とLEDが消えてからカードを取り外してください。USBは充電専用、HDMI/ADBは未対応です。SYS/SD1は本体上部、SD2は下部です。FNキーは4個、スティックはありません。プレイ前に[メニュー・終了方法](emulators.ja.md)を確認してください。
